# 참고 제품 조사 기록

2026-10-21의 Focalboard 7.8.9·Kaneo 2.28.3·Outline 1.11.0 비교와 #37 UI 작업 기록이다.
**역사 기록이며 현재 제품 요구사항이나 구현·검증 상태를 나타내지 않는다.**
현재 원칙과 제안의 채택 여부는 [결정 기록](decisions.md)을 따른다.

당시 화면 관찰, 구현·제안·범위 밖 구분, 리뷰 및 브라우저 확인은
[조사 원문](https://github.com/fvoci/GroundZero/blob/6ecad60f737363dfb0ffb7cf79b623ac84871761/docs/reference-products-survey.md)과
[개발 기록의 참고 제품 비교](https://github.com/fvoci/GroundZero/blob/6ecad60f737363dfb0ffb7cf79b623ac84871761/docs/development.md#86-uiux-점검-모듈-흐름-참고-제품-비교-개발-예제-보강-2026-10-21-featui-module-flows-시작-main-f9700d7)에 보존한다.

관련 결함이나 SHA를 조사할 때만 원문을 연다. 원문에서 참조한 저장소 밖 스크린샷·로컬 데이터가
현재도 남아 있다고 보장하지 않는다. 다른 제품의 기능 목록을 GroundZero의 승인 범위로 해석하거나
로고·아이콘·문구·화면 구성을 가져오지 않는다.
