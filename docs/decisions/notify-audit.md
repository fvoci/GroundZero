# 결정 기록 · 홈·알림·활동·감사·검색

[결정 기록 색인](../decisions.md)의 한 주제다. 번호·앵커(`#d-xx`)는 색인 전체에서 고유하다. 아래 "현재 규칙 요약"은 이 주제의 유효한 규칙을 줄인 것이고, 정본은 그 아래 조항이다. 조항 안의 "개정 2026-10-25"는 그날 바뀐 문구이며 이전 문장은 조항의 원문 연결 또는 [개정 전 판](https://github.com/fvoci/GroundZero/blob/8349771265af71e70d628bd48abe94f815d8f29c/docs/decisions.md)에서 본다.

## 현재 규칙 요약

- 홈은 현재 조직의 요약이다. 빠른 추가는 제목 줄 단추로 펼치고 담당=나가 기본이다(D-19, D-120).
- "내 업무"는 담당이 나인 업무이며 기한 없는 것도 포함하고 워크스페이스별로 묶는다(D-120).
- 알림함은 목록·상세 두 판, 상세를 보면 읽음, 초대는 `invite` 종류로 들어온다. 안 읽은 수는 서버가 센다(D-118). 채널은 앱 내 알림과 선택적 이메일이다(D-55).
- 활동 피드는 감사와 분리한 `activity` 표이며 열람은 대상 접근 검사다(D-119).
- 감사로그는 관리·보안 사건을 남기고 공간·조직·서버·개인 단위로 열람하며 보존 기간은 운영 설정이다(D-28, D-57).
- 검색은 Meilisearch 색인 뒤 서버가 권한을 다시 검사하고, 날짜는 사용자 시간대 경계로 비교한다(D-39, D-101, D-102).

## 조항

<a id="d-19"></a>

- **D-19 홈 구성.** 홈은 현재 조직의 요약이다(D-120). 제목 줄 단추로 펼치는 빠른 업무 추가·주간 달력/가까운 일정·기한 초과/오늘/다가오는/날짜 없는 내 업무·수동 고정·진행 중 다섯 유형 항목·최근 문서/작업·즐겨찾기·최근 활동(D-119)·알림을 둔다. 실행 중 시간 기록은 홈 구역이 아니라 상단의 "기록 중" 표시다(D-117). 업무 완료율·강의 이수율·공부 목표 등 서로 다른 진행률을 같은 의미로 합산하지 않는다. 근거: 초안 §6; 개정 2026-10-25 사용자([원문](https://github.com/fvoci/GroundZero/blob/8349771265af71e70d628bd48abe94f815d8f29c/docs/decisions.md#d-19)).

<a id="d-28"></a>

- **D-28 감사로그.** 생성·삭제·이름 변경 등의 감사로그를 포함한다. 이벤트·열람·보존은 D-57. 근거: 사용자.

<a id="d-39"></a>

- **D-39 검색·알림·가져오기·복구.** Meilisearch로 문서·업무·항목·자료와 지원 형식 첨부 본문을 검색하고 모듈·담당자·상태·날짜로 거른다. 멘션/댓글/기한/일정/초대 알림(알림함 규칙은 D-118, 활동 피드는 D-119, 개정 2026-10-25), 파일 첨부·CSV 업무/강좌 등록·Markdown 체크리스트 가져오기, 휴지통/복원/버전 보존·반출/백업/DB와 첨부의 일관된 복구를 제공한다. 전체 Markdown·Notion 문서 가져오기는 제외한다(X-04). 검색 결과·요약·역방향 링크·알림은 접근권한을 따르며 철회된 내용이 오래된 색인·캐시로 노출되지 않게 한다. 근거: 초안 §18.

<a id="d-55"></a>

- **D-55 알림 채널.** 앱 내 알림과 선택적 이메일을 지원한다. SMTP 없이도 앱 내 알림으로 쓸 수 있고 브라우저 푸시는 후속(H-03)이다. 구현 상태(2026-10-25 감사): 이메일 채널은 아직 없고 결정은 유지한다. O-12 해소. 근거: 사용자.

<a id="d-57"></a>

- **D-57 감사로그 범위.** 생성·이름 변경·이동·복제·보관·삭제·복구·버전 복원·멤버/권한 변경을 기록한다. 공간 로그는 워크스페이스 관리자, 조직 로그는 조직 관리자, 서버 운영 로그는 서버 관리자, 개인 로그는 소유자가 열람한다(D-112). 보존 기간은 운영 설정이며 만료 삭제를 구현한다(D-124). 협업 활동 피드는 감사와 분리한 activity 표다(D-119). 본문 전체·자격 증명은 기록하지 않는다(개정 2026-10-25). O-16 해소. 근거: 사용자.

<a id="d-101"></a>

- **D-101 검색 날짜의 사용자 시간대 경계(P-24 채택).** 문서/항목/파일 수정 시각, 발생일 없는 기록 수정 시각, 시각 일정 시작은 사용자 시간대(D-81)의 하루 경계를 서버가 계산해 비교한다(DST의 23/25시간 포함). 마감일·종일 시작일·기록 발생일은 날짜 그대로 비교한다. 색인과 대체 SQL 의미를 맞추고 필요한 색인 변경·전체 재색인을 한다. 옛 호환용 day는 제거하되 현재 날짜 전용 필드는 유지한다(D-92). 구현 기록: [제거 전 검색 계약](https://github.com/fvoci/GroundZero/blob/8349771265af71e70d628bd48abe94f815d8f29c/docs/development.md#search-contract).

<a id="d-102"></a>

- **D-102 작성자 검색의 색인 필터(P-25 채택).** 300개 후보를 받은 뒤 거르는 대신 작성자 조건을 색인 필터에 넣는다. D-39의 접근권한 원칙에 따라 서버가 결과의 최종 권한을 다시 검사하며 색인 필터로 대체하지 않는다. 대체 SQL과 의미를 맞추고 300개 뒤의 유효 결과를 찾는 회귀 시험을 둔다. 재색인은 D-101과 한 번에 한다. P-14는 관련 제안 기록이며 이 요구의 근거는 본 결정이다.

<a id="d-118"></a>

- **D-118 알림함.** 목록과 상세 두 판이다. 목록에서 골라 상세가 보이면 읽음으로 처리한다. 초대는 알림 종류 `invite`로 알림함에 들어오고 상세에서 수락·거절한다(D-82의 "초대는 알림함"의 구현). 초대만은 현재 조직 범위의 예외로, 아직 속하지 않은 조직·공간의 초대도 어느 조직 문맥에서나 보인다(구현 해석, 사용자 결정 밖). 안 읽은 수는 서버가 세고 목록은 커서로 더 본다. 개별·전체 읽음 실패는 화면 안에 표시하고 재시도를 둔다. 접근을 잃은 알림은 목록에서 빠진다(D-39). 근거: 사용자(2026-10-25).

<a id="d-119"></a>

- **D-119 활동 피드.** 감사로그와 분리한 `activity` 표에 댓글 작성·업무 상태 변경·칸반 이동·담당 지정/해제·생성·이동·공간 제거에 따른 해제를 대상별로 기록한다. 열람은 대상의 `app_access`로 검사한다. 홈에 "최근 활동", 항목에 활동 탭을 둔다. 보존 기간은 조직 한도(D-124)다. 감사로그(D-57)의 사건 목록은 줄이지 않는다. 생성·이동처럼 두 목록에 다 있는 사건은 두 곳에 모두 남기고, 댓글·상태·칸반·담당은 활동에만, 멤버/권한·공개 링크·설정·삭제/복구·관리자 참여는 감사에만 남긴다(구현 해석, 사용자 결정 밖). 근거: 사용자(2026-10-25).

<a id="d-120"></a>

- **D-120 내 업무와 홈.** "내 업무"는 담당자가 나인 업무다(담당 없는 내 작성은 아니다). 기한 없는 업무를 "날짜 없음" 묶음으로 포함한다. 범위는 현재 조직 전체이며 워크스페이스별로 묶는다. 홈의 빠른 추가는 제목 줄 단추로 펼치고 담당=나를 기본값으로 만들어 내 업무에서 빠지지 않게 하며 마지막에 쓴 항목을 기억한다. "진행 중 항목"은 status=active인 항목이다. 홈은 현재 조직의 요약이다(D-19). 근거: 사용자(2026-10-25).
