# 결정 기록 · 계정·인증

[결정 기록 색인](../decisions.md)의 한 주제다. 번호·앵커(`#d-xx`)는 색인 전체에서 고유하다. 아래 "현재 규칙 요약"은 이 주제의 유효한 규칙을 줄인 것이고, 정본은 그 아래 조항이다. 조항 안의 "개정 2026-10-25"는 그날 바뀐 문구이며 이전 문장은 조항의 원문 연결 또는 [개정 전 판](https://github.com/fvoci/GroundZero/blob/8349771265af71e70d628bd48abe94f815d8f29c/docs/decisions.md)에서 본다.

## 현재 규칙 요약

- 인증은 OIDC 전용이며 issuer+subject로 식별하고 같은 이메일로 자동 병합하지 않는다. 자체 비밀번호·SAML은 제외다(D-45).
- 단일 IdP를 유지하고 조직별 IdP 연결은 자리만 둔다(D-45, D-111).
- 초대는 로그인 뒤 대상 확인으로 수락하고 링크 소지만으로 가입하지 않는다(D-51).
- 초기 서버 관리자는 운영자가 지정한 OIDC 식별자를 시드하며 첫 로그인 자동 관리자는 금지다. 조직은 서버 관리자가 만들고 워크스페이스는 조직 멤버 누구나 만든다(D-51, D-112).
- 마지막 소유자는 인계 없이 탈퇴할 수 없고 인계는 수신자 수락으로 끝난다(D-51).

## 조항

<a id="d-45"></a>

- **D-45 인증 방식: OIDC 전용.** Keycloak을 기준 제공자로 검증하되 전용 API에 불필요하게 의존하지 않는다. 로그인·자격 증명·비밀번호 복구·MFA는 제공자, 앱 세션·프로필·초대·멤버십·역할·문서 권한은 fvoci가 담당한다. 로그인만으로 모든 공간 권한을 주지 않고 issuer+subject로 식별하며 같은 이메일로 자동 병합하지 않는다. 격리된 Keycloak으로 로그인/만료/로그아웃/권한 거부를 시험한다. 초기 관리자·초대는 D-51, 선택적 Keycloak 배포는 O-25, 자체 비밀번호 인증·SAML은 제외한다(X-09). 조직별 IdP 연결은 자리만 두고 단일 IdP를 유지한다(D-111, 개정 2026-10-25). O-13 해소. 근거: 인증 지침.

<a id="d-51"></a>

- **D-51 계정·초대·인계·삭제·초기 관리자.** OIDC 로그인 뒤 대상 확인을 거쳐 초대를 수락한다(링크 소지만으로 가입 금지). 마지막 소유자는 인계 없이 탈퇴할 수 없고 인계는 수신자 수락으로 완료한다. 공간 삭제는 소유자가 확인 후 휴지통으로 보낸다(D-41). 초기 서버 관리자는 운영자가 지정한 OIDC 식별자를 `server_admins`에 시드한 것이며(D-112) 첫 로그인 자동 관리자는 금지한다(X-10). 조직은 서버 관리자가 만들고 첫 조직 관리자를 지정하며, 조직 안 워크스페이스는 조직 멤버 누구나 만들고 만든 사람이 소유자다(개정 2026-10-25). 조직 관리자가 하는 공간 삭제도 확인 뒤 휴지통으로 가고(D-41), 소유자 이전도 수신자 수락으로 완료한다(구현 해석, 사용자 결정 밖). O-06 해소. 근거: 사용자.
