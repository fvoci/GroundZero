# 결정 기록 · 모듈별 기능

[결정 기록 색인](../decisions.md)의 한 주제다. 번호·앵커(`#d-xx`)는 색인 전체에서 고유하다. 아래 "현재 규칙 요약"은 이 주제의 유효한 규칙을 줄인 것이고, 정본은 그 아래 조항이다. 조항 안의 "개정 2026-10-25"는 그날 바뀐 문구이며 이전 문장은 조항의 원문 연결 또는 [개정 전 판](https://github.com/fvoci/GroundZero/blob/8349771265af71e70d628bd48abe94f815d8f29c/docs/decisions.md)에서 본다.

## 현재 규칙 요약

- 모든 모듈은 업무·문서·체크리스트·첨부·시간·일정·권한·알림·감사 정본을 공유하고 모듈 전용 정본은 강좌/회차/진도·스터디 계획·항목 기록뿐이다(D-78).
- 업무 완료는 공유, 강의·스터디 진행은 개인별이다. 진도 집계만 함께 보고 시간 집계는 보지 않는다(D-78, D-117).
- 프로젝트: 항목별 업무 상태 정의, 산출물·위험·회고·템플릿, 보관/복구(D-33). 연구: 문헌·자료 버전·분석 연결 고정, Zotero는 읽기만(D-34, D-35). 스터디: 계획 단위·복습·모임(D-36). 강의: 회차·진도·만료 알림, 질문·복습 기록(D-37, D-123). 취미: 활동·재료·결과물(D-38).
- 모듈 인스턴스마다 항목·업무·문서가 한 번호열을 쓴다(D-48).

## 조항

<a id="d-33"></a>

- **D-33 프로젝트 모듈.** 생성/수정/복제, 키·이름·설명·아이콘·리더·멤버·그룹·목표·범위·기간·공개 설정, 항목별 업무 상태 정의(D-116, 개정 2026-10-25), 공통 업무/하위 업무/체크리스트/담당자/우선순위/마일스톤/의존/반복/보기/시간을 제공한다. 요구사항·설계·회의록·결정·매뉴얼·인계 문서, 산출물·완료 기준·위험·문제·회고·재사용 템플릿, 보관/해제/삭제/복구를 포함한다. 근거: 초안 §12.

<a id="d-34"></a>

- **D-34 연구 모듈.** 이름·분야·키워드·책임자·공동 연구자·질문·가설·모형·방법·표본·기간·상태를 관리한다. 문헌은 저자/연도/학술지/DOI/URL/PDF·읽기 상태/태그/요약/인용/페이지 연결, 개인/공동 노트·선행연구 비교·계획서·개념/변수/측정/용어집·실험/인터뷰/랩미팅/피드백/결정/설계 변경 기록을 포함한다. 자료는 파일/외부 위치/출처/수집일/버전·변수 사전/코드북·원자료/정제/분석 자료 구분·결측/제외/품질/권한, 분석은 목적/담당/상태/입력 자료와 코드의 버전/설정/로그/오류/실행 시각/표/그림/재실행 비교를 관리하고 이전 버전·분석 당시 연결을 보존한다. 코드는 외부에서 실행하고 앱은 파일·로그·결과·연결을 관리하며 사람 작업과 컴퓨터 실행 시간을 구분한다. 연구 업무·칸반/달력/간트/마일스톤, 논문/투고 대상/학회·제출/수정 마감·공동저자 검토/제출 체크리스트·제출본/심사의견/답변서·투고/심사/수정/게재 상태, 필요 시 IRB 자료·일정을 제공한다. Zotero는 서지 정보·컬렉션 읽기·원본 링크만 지원한다(X-02·X-03·X-05). 근거: 초안 §13.

<a id="d-35"></a>

- **D-35 연구 자료 버전 관리.** 첫 파일은 v1, 같은 자료에 새 파일을 올리면 v2·v3으로 추가하고 이전 버전을 보존한다. 버전별 업로더·시각·설명을 기록하고 분석의 데이터·코드·결과 파일 연결은 특정 버전에 고정한다. 최신 파일이 바뀌어도 과거 연결을 유지하며 이전 버전 열람·다운로드를 제공한다. 파일 내부 diff·코드 실행·자동 실험 추적은 제외한다(X-02·X-03). 근거: 사용자.

<a id="d-36"></a>

- **D-36 스터디 모듈.** 주제·목표·기간·참여자·수준·목표 분량, 책/논문/문제집/웹 자료·강좌 연결·교육과정/챕터/단계/선행 학습, 일·주 계획·페이지/문제 수/목표 시간·계획 대비 진행/남은 분량/미완료 재배치·개인/공동 계획을 제공한다. 개념/요약/질문/답변/오답/실습 문서, 복습/반복/취약 영역/알림, 모임/발표/진행자/준비/출석, 공동 문서/피드백/시험/점수/회고, 공통 보기·시간 기록을 포함한다. 근거: 초안 §14.

<a id="d-37"></a>

- **D-37 강의 모듈.** 강좌는 이름/과목/강사/플랫폼/링크/교재·수강 시작/만료/목표 완료일·총 회차/영상 길이/상태, 회차는 번호/제목/챕터/영상 길이/링크/자료/교재 범위·수강 예정/완료일·미수강/수강 중/완료·마지막 시청 위치/문서/질문/복습을 관리한다. 날짜별 복수 회차 배정·일/주 계획, 완료/진행/남은 회차·오늘 예정/완료/남은 회차·지연, 회차 수와 영상 길이 기준 진도, 남은 분량/하루 필요 분량·만료/마감 알림을 제공한다. 완료는 직접 표시하고 재수강은 시간만 늘려 완료 수를 중복 증가시키지 않는다. 놓친 회차는 지연으로 남고 사용자가 재배치하며, 목차 추가 때 진도를 갱신해 알린다. 강좌·목차·회차 길이·공동 문서·개인별 진도 공유와 공통 계획/개인별 날짜 조정을 지원하되 개인 상세 시간·메모는 공유하지 않는다(시간 기록은 D-117). 질문·복습은 기록 종류 `question`·`review`로 두고 복습 알림을 보낸다(D-123, 개정 2026-10-25). 실제 인강 시간과 순공부시간을 구분한다. 외부 자동 시청 추적은 H-02이며 수동 입력·자체 타이머로 기본 사용이 가능해야 한다. 근거: 초안 §15·사용자.

<a id="d-38"></a>

- **D-38 취미 모듈.** 활동/창작 프로젝트 이름·유형·목표·기간·참여자·개인/공동 활동, 아이디어/업무/체크리스트/우선순위/반복 연습/마감·방법/레시피/자료/매뉴얼, 사진/영상/과정/실패/배운 점, 재료/장비 보유·필요·준비/설정/사용 기록, 활동 날짜/시간/참여자/결과·결과물/포트폴리오/회고/다음 목표, 공통 보기·시간 기록을 제공한다. 근거: 초안 §16.

<a id="d-48"></a>

- **D-48 번호 체계.** 모듈 인스턴스마다 항목·업무·문서가 한 번호열을 공유한다. 유형과 무관하게 번호가 중복되지 않으며 화면에서는 유형 아이콘·제목으로 구분한다. O-01 해소, P-03 채택. 근거: 사용자.

<a id="d-78"></a>

- **D-78 모듈별 기능 대조와 공통 구현 원칙.** 새로운 범위를 늘리지 않고 D-31~D-38과 기존 구현을 재사용한다. 2026-10-17의 구현/검증 상태표는 [제거 전 개발 지침](https://github.com/fvoci/GroundZero/blob/8349771265af71e70d628bd48abe94f815d8f29c/docs/development.md)의 역사 기록이다. 근거: 사용자.
  - 모든 모듈은 업무·문서/리비전·체크리스트(업무 행/문서 본문 노드)·첨부/버전·시간 기록(일/공부/강의/휴식/기타 및 아래 취미)·일정·권한·알림·감사 정본을 공유한다. 칸반/목록/달력/간트는 같은 업무 목록을 보고 다시 읽은 변경을 함께 반영한다.
  - 모듈 전용 정본은 강좌/회차/개인 진도, 스터디 계획 단위/개인 진행, 항목 기록(연구 문헌/데이터/변수/분석/투고, 프로젝트 산출물/위험/문제/회고, 스터디 자료/모임/시험/복습, 취미 재료/장비/사용/활동/결과물)이다.
  - 업무 완료는 공유, 강의·스터디 진행은 개인별이다. 진행 행은 본인만 읽고 함께 보기에는 진도 집계만 쓴다(시간 기록 집계는 아니다, D-117). 재수강은 시간만 늘리고 완료 수는 유지한다.
  - 모듈(키/이름/아이콘)→항목(제목/설명/정보/리더/멤버/공개)→업무/문서/일정/첨부/기록/전용 패널→보관/휴지통/복구 흐름을 제공한다. 칸반·달력·표시는 D-79~D-81이다. 항목별 시간은 같은 기록의 업무/회차/스터디 단위 대상을 종류별로 모으며 본인 기록만 보여준다(D-117, 개정 2026-10-25).
  - 사용자 선택: 관리자용 모듈 설명, 모듈 휴지통·관리자만 복구, 시간 종류 ‘취미’를 추가한다. 모듈 행만 휴지통에 넣고 복구하며 앞서 따로 지운 항목은 자기 묶음에 남긴다. 항목 공개·멤버를 바꿔 권한을 넓히지 않는다.

<a id="d-123"></a>

- **D-123 강의 모듈의 질문·복습 기록.** 회차 기록 종류에 `question`·`review`를 더하고 복습 알림을 보낸다(D-37의 질문/복습). 근거: 사용자(2026-10-25).
