# GroundZero 실행 증거 — 2026-10-24

이 브랜치는 실행 증거 전용이다. 제품 `main`이나 기능 PR로 병합하지 않는다. 기본 소스 트리에 원시 로그와 실험 도구를 누적하지 않기 위해 분리했다.

## 문서 크기 계산 실험 B — 기각

기준은 `22ad80ee205332e3ef1ffd8f64f783789955921b`, Rust 1.99.0 및 해당 Cargo.lock이다. 버퍼를 없앤 후보는 결과·오류 동등성 시험을 통과했지만, 세 번의 교대 측정에서 이스케이프 문자열은 18–20%, 깊은 구조는 22–24% 느려져 사전 기준에 따라 기각했다. 2MB 사례의 약 52% 개선과 버퍼 감소만으로 채택하지 않았다.

실험 제품 패치와 회귀시험은 별도 추적 브랜치 `fvoci/ablation-body-size`의 `76e21f6`에 보존했다. PR을 만들거나 main에 채택하지 않았다. `ablation/B/`에는 가설·보고·원본 표본·통계·재현용 작은 Rust/셸 도구를 보존한다. 컴파일 산출물은 기존 툴체인과 잠금 파일로 재생성할 수 있어 제외했다. `ablation/B/artifacts.sha256`은 이 저장소에 실제 보존한 파일의 체크섬이다.

## 추가 후보의 정적 선별

`ablation/wave2/proposal.md`는 홈 화면 요청 병렬화(D)의 실패 배너 순서 반례, 고정·즐겨찾기 조회(E)의 실험 조건, Up Next(F)의 근거 부족을 구분한다. D/F의 성능 실험은 실행하지 않았으며, E의 채택을 이 문서가 승인하지 않는다.

## 검색 텍스트 계산 실험 A — 초기 기준 검증

`ablation/A/`에는 초기 고정 기준의 문자열 동등성 검증, 교대 측정 원본과 재현 방법, 시험 DB 소유권·정리 근거를 보존한다. 허용 목록과 체크섬은 `ablation/A/archive/`에 있다. PR #122의 최종 채택은 의존성 업데이트를 반영한 재검증을 별도로 거쳐야 한다. 이 초기 기록은 그 후속 검증을 대신하지 않는다.

비밀번호·토큰·연결 문자열·사용자 데이터·이미지는 이 증거에 포함하지 않는다. 시험 입력은 합성 데이터다. 실제 실행 조건·한계와 PASS/FAIL/NOT RUN은 각 보고를 따른다.
